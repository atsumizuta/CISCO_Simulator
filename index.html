1. システム基盤・ハードウェア制御

hostname Spine_A
vdc Spine_A id 1
limit-resource vlan minimum 16 maximum 4094
limit-resource vrf minimum 2 maximum 4096
limit-resource port-channel minimum 0 maximum 511
limit-resource m4route-mem minimum 58 maximum 58
limit-resource m6route-mem minimum 8 maximum 8
【機器の根幹とリソース配分（VDC）】
物理スイッチを論理的に分割する「VDC」の設定です。m4route-mem minimum 58 maximum 58 は、「IPv4マルチキャスト（MoIPの映像・音声）の経路を記憶するためのメモリ58MBを、他の処理に奪われないよう上限・下限ともに固定して完全にロック（専有）する」という、放送事故を防ぐための強い意志が込められた設計です。
line console
line vty
boot nxos bootflash:/nxos64-cs.10.4.5.M.bin
🔌 【ログイン制御と起動OS】
  • line console / vty: スイッチに直接ケーブルを挿す「コンソール接続」と、TeraTerm等で遠隔から入る「VTY接続（SSH等）」の入り口の設定です。
  • boot nxos ...: スイッチを再起動した際に「必ずこのバージョンのOS(NX-OS)ファイルを使って起動しなさい」という絶対的な指示です。意図しない古いバージョンで立ち上がるのを防ぎます。
feature telnet
feature nxapi
feature ospf
feature pim
feature interface-vlan
feature hsrp
feature dhcp
feature ptp
feature lldp
【機能のアンロック（Feature設定）】
Nexusスイッチは初期状態では高度な機能が封印されています。ここで必要な能力をONにします。

2. NW共通・ルーティング (L2/L3/Multicast)

ip pim ssm range 232.0.0.0/8 239.69.0.0/16
ip igmp ssm-translate 239.69.171.0/24 10.234.88.35
🎯 【マルチキャスト制御の中核 (SSM)】
古い機材（IGMPv2）が「239.69.171.xが見たい」と言ってきた際、スイッチが気を利かせて「送信元は10.234.88.35だよ」と翻訳してあげる救済措置（マッピング表）です。
vrf context management
ip route 0.0.0.0/0 10.211.0.1
vrf context Control1
ip route 10.198.28.0/30 Vlan100 vrf Media
🚀 【VRFとルーティング (デフォルトルート / リーキング)】
ip route [宛先] Vlan100 vrf Media は「Route Leaking（ルートリーキング）」と呼ばれる高度な技術です。本来完全に隔離されているControl網とMedia網の間で、ピンポイントで通信の穴を開けています。
