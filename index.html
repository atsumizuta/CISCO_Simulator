1. システム基盤・ハードウェア制御

hostname Spine_A
vdc Spine_A id 1
limit-resource vlan minimum 16 maximum 4094
limit-resource m4route-mem minimum 58 maximum 58
【機器の根幹とリソース配分（VDC）】
物理スイッチを論理的に分割する「VDC」の設定。m4route-mem minimum 58 maximum 58 はマルチキャスト（MoIPの映像・音声）経路用のメモリを完全にロック（専有）し、放送事故を防ぐための強い意志が込められています。
boot nxos bootflash:/nxos64-cs.10.4.5.M.bin
🔌 【起動OSの固定】スイッチ再起動時に必ず指定バージョンのOSで起動する絶対的な指示です。

2. NW共通・ルーティング (L2/L3/Multicast)

ip pim ssm range 232.0.0.0/8 239.69.0.0/16
ip igmp ssm-translate 239.69.171.0/24 10.234.88.35
🎯 【マルチキャスト制御 (SSM)】
IGMPv2の古い機材が映像を要求した際、スイッチが気を利かせて「送信元はこれだよ」と翻訳してあげる救済措置（マッピング）です。
vrf context Control1
ip route 10.198.28.0/30 Vlan100 vrf Media
🚀 【VRFとRoute Leaking】
本来完全に隔離されているControl網とMedia網の間で、ピンポイントで通信の穴を開ける高度なルーティング技術です。
